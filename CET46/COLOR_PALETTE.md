## 🎨 颜色使用场景

### 1. 背景组合
```css
/* 深木色基底 + 8x8 像素网格 */
background-color: #2e1e18;
background-image: linear-gradient(45deg, #3a261f 25%, transparent 25%);
```

**效果:** 深邃的矿洞/工坊氛围

### 2. 木质面板
```css
/* 3D 凸起效果 */
background-color: #e2a053;
border: 4px solid #2b1100;
box-shadow: 
  inset 4px 4px 0px #ffcca6,      /* 左上高光 */
  inset -4px -4px 0px #b16223;    /* 右下阴影 */
```

**效果:** 像素风格 3D 木质按钮

### 3. 燃料条 (体力条)
```css
/* 分段式绿色条纹 */
background: repeating-linear-gradient(
  to bottom,
  #63c74d 0%,
  #63c74d 60%,
  #3e8948 60%,
  #3e8948 100%
);
```

**效果:** 星露谷经典体力条

### 4. 温度条 (过热条)
```css
/* 分段式红色条纹 */
background: repeating-linear-gradient(
  to bottom,
  #e43b44 0%,
  #e43b44 60%,
  #a22633 60%,
  #a22633 100%
);
```

**效果:** 危险温度警告

### 5. 文本颜色
```css
/* 暖白色文本，柔和不刺眼 */
color: #fbe6c4;
```

**效果:** 像素游戏经典文本色

## 🎨 颜色情感分析

### 暖色系 (木色、金色)
- **情感:** 温暖、自然、舒适、怀旧
- **应用:** 主面板、背景、装饰
- **心理:** 降低学习压力，增强沉浸感

### 绿色系 (体力条)
- **情感:** 能量、健康、成长、安全
- **应用:** 燃料指示、成功反馈
- **心理:** 正向激励，促进学习动力

### 红色系 (温度条)
- **情感:** 警告、危险、紧迫、激情
- **应用:** 过热警告、错误提示
- **心理:** 引起注意，避免疲劳学习

### 中性色 (深棕、暖白)
- **情感:** 稳定、专业、平衡
- **应用:** 边框、文本、背景
- **心理:** 提供视觉稳定性，避免过度刺激

## 📱 响应式颜色适配

### 深色模式 (自动)
```css
/* 深木色背景在暗光环境下更舒适 */
@media (prefers-color-scheme: dark) {
  :root {
    --sv-bg-base: #2e1e18;  /* 保持不变 */
  }
}
```

### 浅色模式 (不推荐)
```css
/* 如果必须支持浅色模式 */
@media (prefers-color-scheme: light) {
  :root {
    --sv-bg-base: #f5e6d3;  /* 浅木色 */
    --sv-text-light: #2b1100; /* 深色文本 */
  }
}
```

**建议:** 星露谷风格最适合深色模式

## 🎨 配色技巧

### 60-30-10 法则
```
60% 主色：#2e1e18 (深木色背景)
30% 辅色：#e2a053 (木质面板)
10% 强调色：#63c74d (体力绿) / #e43b44 (过热红)
```

### 色彩和谐
- **类似色:** #2e1e18 → #3a261f → #e2a053 (木色系)
- **对比色:** #63c74d (绿) vs #e43b44 (红)
- **三色和谐:** #e2a053 (木) + #63c74d (绿) + #2b1100 (棕)
