## 🎮 游戏化功能

### 学习反馈循环
```
成功学习 → 引擎获得燃料 (+5) → 温度降低 (-2) → 金色粒子庆祝
连续错误 → 燃料减少 (-2) → 温度升高 (+8) → 红色警告
燃料耗尽 → 引擎卡壳 (黑白) → 需要休息
完美表现 → 持续粒子特效 → 成就解锁
```

### 状态机系统
| 状态 | 触发条件 | 视觉效果 | 用户提示 |
|------|----------|----------|----------|
| SLEEPING | 初始状态 | 灰色核心，微弱脉动 | "* 引擎正在休眠 *" |
| SMELTING | 燃料>0 且 温度<85 | 金色核心，绿色粒子 | "* 引擎正在工作 *" |
| OVERHEATED | 温度≥85 | 红色核心，抖动动画 | "* 引擎过热，请休息 *" |
| JAMMED | 燃料≤0 | 黑白滤镜，无光 | "* 燃料耗尽，需要休息 *" |

## 🎯 核心改造亮点

### 1. 纯 CSS 8x8 像素网格 🎨
**技术:** 4 个 linear-gradient 以 45°/-45° 交错  
**优势:** 零图片加载，完美缩放，性能极佳  
**代码:**
```css
background-image: 
  linear-gradient(45deg, #3a261f 25%, transparent 25%), 
  linear-gradient(-45deg, #3a261f 25%, transparent 25%), 
  linear-gradient(45deg, transparent 75%, #3a261f 75%), 
  linear-gradient(-45deg, transparent 75%, #3a261f 75%);
background-size: 8px 8px;
```

### 2. 3D 木质面板 🏗️
**技术:** box-shadow 内阴影模拟光照  
**效果:** 像素风格 3D 凸起  
**代码:**
```css
box-shadow: 
  inset 4px 4px 0px #ffcca6,      /* 左上高光 */
  inset -4px -4px 0px #b16223,    /* 右下阴影 */
  4px 4px 0px rgba(0,0,0,0.2);    /* 外部投影 */
```

### 3. 分段式进度条 📊
**技术:** repeating-linear-gradient  
**效果:** 星露谷经典条纹质感  
**代码:**
```css
background: repeating-linear-gradient(
  to bottom,
  #63c74d 0%,
  #63c74d 60%,
  #3e8948 60%,
  #3e8948 100%
);
```

### 4. 粒子特效系统 ✨
**技术:** CSS 动画 + DOM 元素  
**动画:** sv-particle-rise (2s 上升 + 淡出)  
**触发:** 成功学习时生成 3-5 个粒子
