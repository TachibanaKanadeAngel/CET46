## 🔍 启动测试步骤

### 方法 1: 使用 Live Server (推荐)
```bash

# 右键 index.html -> "Open with Live Server"
# 或使用命令行
npx http-server . -p 8080
```

```bash

python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```

### 方法 3: 直接打开文件
```bash

start index.html
```

```css
-webkit-font-smoothing: none;  /* 关闭抗锯齿 */
font-smoothing: none;
image-rendering: pixelated;     /* 像素化渲染 */
```

## 🐛 常见问题排查

### 问题 1: 背景没有像素网格
**原因**: CSS 未正确加载
**解决**: 检查浏览器开发者工具 Console，确认 sv-theme.css 加载成功

### 问题 2: 引擎不工作
**原因**: JavaScript 模块导入失败
**解决**: 检查 main.js 中是否正确导入 engine-visualizer.js

### 问题 3: 粒子特效不显示
**原因**: 浏览器不支持 CSS 动画
**解决**: 更新浏览器到最新版本，或检查是否禁用了 CSS 动画

### 问题 4: 移动端布局异常
**原因**: 视口设置错误
**解决**: 确认 `<meta name="viewport">` 标签存在
