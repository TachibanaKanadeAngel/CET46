# 46英语 (CET46)

基于现代间隔重复算法（FSRS）的高效英语四六级单词记忆工具。支持 Web PWA 与微信小程序双端同构运行，采用零隐私采集的离线优先架构，帮助学习者以科学的方法攻克核心词汇。

---

## 🌟 项目简介

46英语专为准备大学英语四级（CET-4）与六级（CET-6）考试的学习者打造。系统摒弃了传统词库死记硬背的低效模式，全面引入现代间隔重复记忆引擎 **FSRS（Free Spaced Repetition Scheduler）**，动态建模每个单词在大脑中的遗忘衰减曲线，在临界遗忘点精准调度复习。

### 核心亮点
- **零隐私保护**：100% 离线优先架构，无云端用户行为跟踪，不采集设备信息、剪贴板等任何敏感权限。
- **双端同构设计**：一套算法核心同时驱动 Web PWA（现代浏览器/桌面端）与原生微信小程序端。
- **自主可控数据**：本地 IndexedDB / 小程序持久存储，并支持可选的 WebDAV 端到端加密（AES-GCM）多端私有同步。

## 📚 内容与功能特性

### 1. 体系化词库覆盖
- **CET-4 核心词库**：覆盖大学英语四级大纲核心考查词汇。
- **CET-6 拓展词库**：覆盖大学英语六级大纲进阶词汇。
- **四级高频必背词库**：按历年真题出现频次深度筛选的高频词汇精选集。
- **自定义词库导入**：支持用户导入自定义 JSON / CSV 格式词表，满足考研、雅思、托福等扩展需求。

### 2. 人性化学习与复习交互
- **个性化批次计划**：内置 25、50、100 词经典学习规模，并开放**任意数量自定义输入**，无论是考前冲刺还是日常慢学均可精准适配。
- **难度模式随心切换**：
  - **标准模式**：默认展开释义与音标，提供平滑记忆体验；
  - **高难度模式**：可一键折叠隐藏音标与中文释义，强化主动回忆（Active Recall），达到最佳记忆编码效果。
- **完整学习闭环**：
  - **快速自测**：新词学习流转支持「认识 / 不认识」闪电决策；
  - **智能复习**：结合 FSRS 四级评分机制（Again / Hard / Good / Easy）动态调整调度；
  - **拼写巩固**：提供音标与提示辅音的拼写默写练习；
  - **配对小游戏**：趣味 3×3 词义连线，提升碎片化背词趣味度；
  - **错词回流本**：错词即时插入复习队列并在错题本归档，直至彻底掌握。

## 🧮 记忆模型与算法计算原理

本项目算法引擎基于 **FSRS 4.5（Free Spaced Repetition Scheduler）** 算法体系。该算法在认知科学界被证实相比传统的 SM-2 算法具备更高的预测准确度与复习效率。

### 1. 记忆状态三大维度
每个单词在记忆库中由三元组状态唯一表示：
- **稳定性 $S$（Stability）**：记忆的牢固程度。定义为：**在当前状态下，记忆可提取率从 100% 衰退至目标保留率（如 90%）所需的时间（天）**。
- **难度 $D$（Difficulty）**：单词本身的内在认知难度，取值区间限制在 $[1.0, 10.0]$ 之间，数值越高越难掌握。
- **可提取概率 $R(t)$（Retrievability）**：经过时间 $t$（天）之后，在大脑中成功回忆起该单词的瞬时概率。

---

### 2. 遗忘曲线衰减模型计算

FSRS 采用幂函数模型描述记忆留存率随时间的衰减过程：

$$R(t, S) = \left( 1 + \text{FACTOR} \cdot \frac{t}{S} \right)^{-w}$$

其中各项常数定义如下：
- $t$：距上一次复习已流逝的时间（以天为单位）；
- $S$：该单词当前的稳定性系数；
- $\text{FACTOR} = \frac{19}{81} \approx 0.2345679$：归一化定标常数，保证当经过时间 $t = S$ 时，记忆可提取率正好为 $R(S, S) = 0.9$（即 90% 默认目标保留率）；
- $w$：衰减指数因子。

---

### 3. 下次最佳复习间隔（Interval）计算

为了将整体词汇记忆保持在用户设定的期望保留率 $r$（Desired Retention，系统默认设定为 $0.90$，支持在 $0.80 \sim 0.95$ 间调节），复习调度器通过反解衰减函数精确求得最佳间隔天数 $I(r, S)$：

$$I(r, S) = \frac{S}{\text{FACTOR}} \cdot \left( r^{-1/w} - 1 \right)$$

- 当目标保留率设为默认的 $r = 0.90$ 时：
  $$I(0.9, S) = S \cdot 1.0 = S \text{ 天}$$
- 若用户提高目标保留率至 $r = 0.95$（冲刺考前），计算得出 $I < S$，系统将缩短复习间隔，加大复习密度；
- 若调低保留率至 $r = 0.85$（减负模式），计算得出 $I > S$，系统将拉长间隔，减少每日复习任务量。

---

### 4. 学习评级状态转移机制

复习界面提供四档评级反馈（Grade $G \in \{1, 2, 3, 4\}$）：
- **Grade 1 (Again)**：完全遗忘，稳定性大幅重置，难度 $D$ 提升；
- **Grade 2 (Hard)**：艰难回忆，稳定性按较小倍数递增，难度 $D$ 略微上浮；
- **Grade 3 (Good)**：正常回忆，稳定性按标准指数规律扩增；
- **Grade 4 (Easy)**：轻而易举，稳定性跨越式提升，难度 $D$ 微降。

#### 难度 $D$ 动态更新公式：
$$D' = D - w_6 \cdot (G - 3)$$
$$D_{\text{new}} = w_7 \cdot D_0 + (1 - w_7) \cdot D'$$
（结合均值回归机制防止难度两极极端漂移，并限制边界在 $[1.0, 10.0]$）

#### 成功复习后稳定性 $S$ 更新公式（$G > 1$）：
$$S_{\text{new}} = S \cdot \left( 1 + \exp(w_8) \cdot (11 - D) \cdot S^{-w_9} \cdot (\exp((1 - R) \cdot w_{10}) - 1) \cdot \text{grade\_bonus}(G) \right)$$
*算法特性：当回忆率 $R$ 越接近临界遗忘点时成功回忆，稳定性获得的增益倍数越大（主动困难记忆效应）。*

#### 遗忘重置后稳定性 $S$ 更新公式（$G = 1$）：
$$S_{\text{new}} = w_{11} \cdot D^{-w_{12}} \cdot \left( (S + 1)^{w_{13}} - 1 \right) \cdot \exp((1 - R) \cdot w_{14})$$
确保遗忘后的单词进入再巩固通道，以科学频率重新呈现。

## 🛠️ 技术架构与快速开始

### 技术栈构成
- **核心构建**：Vite + TypeScript
- **前端视图**：原生标准现代 JavaScript (ES Modules) + 响应式 CSS3 + PWA
- **测试框架**：Vitest（单元测试与模拟集成）+ Playwright（端到端）
- **本地存储**：IndexedDB（Web 端） / 微信小程序本地 Storage 分片机制
- **同构算法**：统一的 FSRS 状态机引擎

### 本地运行

1. 安装依赖：
```bash
npm install
```

2. 启动本地开发服务：
```bash
npm run dev
```

3. 运行全套测试验证：
```bash
# 运行核心测试（含单元、集成与算法推导验证）
npm test

# 运行微信小程序模块同构测试
npm run mp:test
```

4. 构建生产产物：
```bash
npm run build
```
